# Dawn Patrol

A 3D surf game built with three.js — single file, runs in any modern browser.

Open `index.html` to play, or visit the GitHub Pages site.

## Controls
- Arrow keys / WASD: carve, pump, set your line
- Turn up into the lip at speed to launch airs
- Shift + direction in the air for grabs and rodeos

## Features
- Hollow, pitching sections and barrels (classic, almond, round)
- Level ladder that auto-advances, plus Free surf and an Ice surf level
- Sharks, seals, dolphins, mantas, pelicans and gulls — don't hit them
